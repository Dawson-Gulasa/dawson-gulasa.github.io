# Personal website assets

The homepage and About page expect **`headshot.jpg`**, the user-supplied professional portrait.

All resume buttons expect **`resume.pdf`**, the user-supplied updated one-page resume. To update your resume in the future, replace this PDF using the same filename.

These files are binary and need to be uploaded to this folder in the review branch before publishing. Do not place the ZIP itself in GitHub.

**Required paths after upload:**

- `assets/headshot.jpg`
- `assets/resume.pdf`
